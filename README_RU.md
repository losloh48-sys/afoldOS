# AFold OS 4.0 Python Glass — Alpha 1.1 (Build 4002)

Сборка основана на существующей Python-оболочке AFold OS Beta 3.0 Build 7584. Это обновление визуального слоя, а не отдельная ОС.

## Что изменено
- Liquid Glass-inspired тёмная палитра и новые градиентные обои.
- Плавающая нижняя панель задач с компактным доком.
- Иконки приложений на панели плавно увеличиваются при наведении курсора и возвращаются к исходному размеру при уходе курсора.
- Улучшены поверхности окон и меню.
- Анимации выполняются через event loop Tkinter без принудительной перерисовки на каждом кадре.
- Сохранены Python/Tkinter, AFold Store, пользователи, настройки, папки данных и встроенные приложения Word Pro и PyExcel.

## Ограничения текущего этапа
Настоящий backdrop blur и физически корректная прозрачность всех окон не реализованы: стандартный Tkinter не предоставляет полноценный compositor. Сейчас применяется лёгкий визуальный glass-слой. Следующий этап — перенос только рендерера на Qt/QML при сохранении Python-логики и структуры данных, если тесты производительности на целевом компьютере это подтвердят.

## Запуск
Распакуйте архив и запустите `start_afold.bat`. Для сохранения пользовательских файлов можно перенести `afold_data` из предыдущей установки.
